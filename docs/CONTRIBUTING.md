# Contributing

Thank you for taking the time to contribute to this project! While trying to stay clear of feature bloat, there are always options for improving existing code or documentation, as well as having an eye on the dependencies. 

## Setup

1. Clone the repo
  ```bash
  git clone https://github.com/nikooozzz/bookswift
  cd bookswift
  ```

2. Install dependencies
  ```bash
  npm install
  ```

3. Run in dev mode
  ```bash
  npm run dev
  ```

This opens a Firefox instance with Bookswift pre-installed and auto-reloading on code changes.

## Guidelines

I expect you as a contributor to follow FOSS collaboration standards, meaning the following:

### Issues

Check any existing issues before opening a new one. For feature requests, open an issue first to discuss the design.

### Pull Requests

Keep PRs focused and single-purpose. Match the existing JavaScript style and keep CSS/DOM scoped using the `bsl-` prefix.

### Code of Conduct

Be respectful and constructive in all discussions. I will not tolerate any form of discrimination or personal attacks whatsoever, so let's focus on the project instead!
