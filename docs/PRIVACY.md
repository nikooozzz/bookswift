# Bookswift Privacy Policy

Bookswift is committed to protecting your privacy!

## Data Collection and Usage
Bookswift does **not** collect, store, track, or transmit any personal data, browsing history, bookmark content, or analytics.

## Local Storage
Any settings, keybindings, or user preferences configured within Bookswift are stored locally on your device via Firefox's standard web extension storage API (`browser.storage.local`). This data never leaves your browser.

## Third-Party Services
Bookswift does not use any third-party analytics, tracking tools, or external remote servers.

## Contact & Open Source
Bookswift is open-source software. You can inspect the source code at any time on [GitHub](https://github.com/nikooozzz/bookswift). If you have any privacy questions, please open an issue in the repository.
