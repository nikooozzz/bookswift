# Bookswift

> A minimalist bookmark launcher for Firefox.

Welcome to the official documentation for **Bookswift**, a keyboard-driven bookmark manager for Firefox.

## Quick Links

- [Privacy Policy](PRIVACY.md)
- [GitHub Repository](https://github.com/nikooozzz/bookswift)

## Usage

1. Install the Bookswift extension from [Firefox Addons](https://addons.mozilla.org/en-US/firefox/addon/bookswift/).

2. Press `Ctrl+Space` (macOS: `Command+Space`) on your keyboard on any website.

3. Search for a saved bookmark

4. Click Enter to open it
