# Bookswift

> A minimalist bookmark launcher for Firefox.

![GitHub Actions Workflow Status](https://img.shields.io/github/actions/workflow/status/nikooozzz/bookswift/release) ![Mozilla Add-on Version](https://img.shields.io/amo/v/:84d0309fe62f4014a262) ![License](https://img.shields.io/badge/license-MIT-blue.svg)

*Our official docs exist at https://nikooozzz.github.io/bookswift*.

## Overview

Bookswift started as a write-and-forget project to resolve my need for a quicker, keyboard-bound bookmark opener to easily resolve bookmark-heavy workflows. It's inspired by app launchers such as [`wofi`](https://hg.sr.ht/~scoopta/wofi)/[`rofi`](https://github.com/davatorium/rofi), [`sherlock`](https://github.com/Skxxtz/sherlock) and macOS's Spotlight. Bookswift is meant to be a minimalistic bookmark launcher with minimal feature bloat and a clean interface.

## Getting Started

Bookswift can be installed through the [Firefox Addon Store](https://addons.mozilla.org) and does not yet provide any configuration options. To open the app launcher, simply press `Ctrl+Space` (`Command+Space` on macOS) and type the name of the bookmark you want to open.
